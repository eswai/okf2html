開発に必要なツールを順にインストールします。所要時間は約30分です。

## 前提条件

Python 3.9 以上が必要です。`python --version` で確認してください。

```bash
python -m venv .venv
.venv/bin/pip install -r requirements.txt
```

| OS | 確認済み |
|----|----|
| macOS | ✓ |
| Windows 11 | ✓ |
